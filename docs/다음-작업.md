## 4. Jev 연동 메모

Feedloop 연동 방식을 따릅니다.

- 흐름: 답장을 LLM이 먼저 분류하고, Jev가 분류만 다시 판정합니다. Jev 확신도가 0.7 이상이면 Jev 결과를 씁니다.
- 비용: Jev 기준 1,000건에 약 $0.07입니다.
- 예비: OpenAI Decisions는 같은 실력에 값이 두 배입니다. 키만 바꾸면 넘어가는 예비 공급자로 둡니다.
