# 디딤칸 수강료 원천 사이트 확인 (2026-10-11)

방법: aside 로 포털 데이터셋 페이지와 원천 사이트를 직접 열어 봄. 읽기만 했고 로그인·신청 버튼은 안 누름. 요청 간 1초 이상 간격. Playwright 안 씀.

## 먼저 알아둘 것

- 파일에 수강료 칸이 없다고 사이트에도 없는 게 아니다. 8곳 중 2곳은 사이트 목록에 있고, 2곳은 상세 또는 공지에만 있다. 사이트에도 없는 곳은 3곳이다.
- 포털 데이터셋 페이지의 「비용부과유무: 무료」는 데이터 내려받기 비용이다. 수강료가 아니다.
- 포털 파일 페이지에는 원천 사이트 URL 칸이 없다. 제공기관·관리부서·갱신주기만 나온다. 원천 사이트는 검색으로 찾았다.
- 서울 3구(서대문·성북·강동) 상세 페이지는 주소에 번호만 붙여 GET 으로 직접 열린다. 어댑터 todo 의 「POST 폼, GET 미확인」은 해소된다. 브라우저에서 로그인 없이 열었다.

## A. 수강료 칸이 없는 파일

### 1. incheon-seo (pk 15051479) → (나) 목록에 있음
- 포털: 제공기관 인천광역시 서해구(옛 서구), 관리부서 정보통신과, 갱신 연간, 수정 2026-09-28, 390행.
- 원천: 서해구청 동주민센터 「자치센터프로그램」. 옛 주소 seo.incheon.kr 은 seohae.go.kr 로 넘어간다.
- 수강료 보임: 목록 카드마다 「수 강 료 : 60,000원」. 가좌3동 목록에서 116건 전부 확인.
- 예시: https://www.seohae.go.kr/dong/program/programInfoList.do?prgmdiv=gajwa3&acptrun=&orderby=regdt
- 동마다 prgmdiv 코드가 달라 동 수만큼 목록을 돌아야 한다. 평생학습관 행은 공식 페이지에서 요금을 못 봤다. 블로그 글에 「수강료 무료」라는 말만 있다.

## 확인 못 한 것
- 인천 서구 평생학습관 행의 공식 요금 페이지.
- 대전 중구 나머지 14개 동, 대전 서구 나머지 동.
- 단양군 HWP 첨부 내용.
- 미추홀구 주안5동.
- 양주 옥정1동 강좌의 원천 위치. 예산·김해 빈 행과 사이트의 일대일 대조.
- 각 사이트의 robots.txt 와 이용약관은 이번에 보지 않았다.
